## DownTube 1.2.0

下载体验大版本：并发下载与阶段显示、断点续传与自动重试、格式扩展（FLAC 无损音频、H.265 转码），并修复了 Cookies 导入与标题解析的多个问题。

### 下载体验

- **并发下载**：可同时下载多个任务，设置 → 下载位置 → 「下载行为」中可选 1–5 个（默认 3）；某个任务完成或暂停后，排队任务自动补位
- **阶段显示**：任务行实时显示当前阶段——「下载视频中 / 下载音频中 / 合并中 / 转换音频中 / 转码 H.265 中」，不再笼统地停留在「准备中」
- **进度更准确**：音视频分离流场景下，进度条按两个流的总体进度折算，不再出现「100% 后又回到 0%」的跳变

### 下载可靠性

- **断点续传**：中断后保留 `.part` 文件，重新开始会从断点继续
- **自动重试**：网络层自动重试之外，任务失败后还会按设置自动重试（默认 2 次，退避间隔），任务行显示「重试中 (1/2)」
- **错误诊断**：常见失败会附带中文排查建议——403（Cookies 失效或代理 IP 受限）、机器人验证（建议提供 Cookies）、地区限制等
- 修复 Windows 下中文错误信息乱码（GBK 解码）

### 格式支持

- **视频默认输出 H.264 + AAC 的 MP4**：兼容性最好，此前默认可能输出 .webm，部分播放器无法打开
- **H.265 / HEVC**：设置 → 画质与格式 → 「视频编码」可选「H.265 · 下载后转码」，下载完成后自动用 FFmpeg 转码为 HEVC（`hvc1` 标记、`+faststart`、音频流直接复制），任务行显示转码进度
- **FLAC 无损音频**：「下载内容」新增「仅音频 · FLAC」；MP3 转换质量提升至最高档

### 修复

- **Cookies 导入**：导入的 cookies.txt 会自动校验并修复常见问题（移除 BOM、补全 Netscape 文件头），格式不合法时给出明确提示；修复「选了文件导入但未选择文件时静默回退浏览器 Cookies」的隐患
- **标题解析**：批量解析失败时自动重试一次，仍失败则显示「未获取到标题，下载时自动解析」而不再一直卡在「正在获取视频信息…」；下载开始时会解析出正式标题，应用重启后自动补解析

### 其他

- 设置页「下载位置」新增「下载行为」卡片（同时下载数、自动重试次数）
- 新增端到端集成测试（并发调度、阶段文案、重试、H.265 转码），通过 `DOWNTUBE_IT=1 go test` 启用
