## DownTube 1.2.4

新增应用内「检查更新」与一键更新。以后有新版本，在应用里点两下就能升级完，不用再自己找安装包、跑安装向导。

> 这一版是更新功能的首发：从 1.2.4 起应用才能自己检测和安装新版本。如果你现在用的是 1.2.3 或更早的版本，还需要手动下载安装这一次；之后就可以一直用应用内更新了。

### 新增

- **检查更新**：启动后自动静默检查一次，不弹窗、不打断你正在做的事，只在侧边栏「关于」上点一个小圆点提示；想主动确认时，到「关于」页点「检查更新」即可，手动检查会给出明确结果（发现新版本 / 已是最新）
- **一键更新**：检测到新版本后显示版本号、更新内容和来源，点「下载更新」在应用内下载（带进度），下载完点「立即安装并重启」——程序自动关闭、后台静默完成覆盖安装、再自动打开新版，全程不需要你操作安装向导
- **下载更省事**：安装包下载后会被记住，中途关掉程序再打开也不用重新下载；下载源以 CNB 为主（国内直连，速度快），CNB 不可用时自动改用 GitHub 备用源

### 安全

- 更新只能从固定域名（CNB、GitHub）下载，安装前还会校验文件完整性，异常文件不会被执行

### 其他

- 更新弹窗里的说明文字做了排版处理，不会再露出 Markdown 标记
- 修复若干细节问题

### 如果你遇到问题

- 检查更新提示失败：多为网络原因，稍后重试即可，也可以点「查看发布页」手动下载安装包
- 更新后如果发现版本没变化：确认安装时没有取消管理员授权弹窗（安装需要管理员权限）
