## DownTube 0.2.0

界面交互与下载体验的一轮集中打磨，另外补上了 FFmpeg 的引导安装。

### 新增

- **FFmpeg 引导安装**：关于与设置页可一键自动下载安装，也可以指向已有的 `ffmpeg.exe`；过程有阶段和百分比提示
- 关于页新增作者入口：主页、B 站、项目仓库，均为带图标的应用内按钮
- 界面动效：开关、输入框、按钮、页面切换都补了过渡反馈

### 改进

- **下载时不再弹出命令行窗口**
- **进度实时刷新**：原来会从 0 直接跳到 100%，现在解析 yt-dlp 的逐行进度输出，速度、已下载大小、剩余时间实时更新
- **添加链接时先解析片名**：批量粘贴后立刻拿到标题，不用等开始下载
- 下载设置不会被后台推送覆盖了：在设置页编辑期间，任务状态刷新不会把你没保存的改动冲掉
- 单实例保护：程序已经在跑时再次启动会提示，而不是开出第二个实例互相覆盖本地数据
- 链接无效时给出明确数量反馈
- 任务排队逻辑统一，取消与完成后都能正确接上下一个

### 修复

- 中文标题乱码（yt-dlp 在 Windows 管道里输出 GBK）
- 本地状态文件损坏时会被备份而不是直接丢掉
