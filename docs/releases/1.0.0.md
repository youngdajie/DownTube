## DownTube 1.0.0

1.0 正式版。界面整体重做并定型：深浅双主题、两步式下载流程、分类设置页；FFmpeg 也换成了更适合国内网络的安装方式。

### 界面

- **全新设计**：去掉旧版的渐变光晕与装饰性元素，改为扁平化专业工具风格——纯色表面、细边框、克制的圆角，主色 `#1296db` 只用于主按钮、激活态与进度等关键位置
- **深色 / 浅色双主题**：标题栏右侧一键切换，选择会被记住（首次跟随系统）
- **标题栏**：左上角显示应用名，右侧为昼夜切换与窗口控制
- **下载页两步式流程**：「添加链接」粘贴来源，支持批量 / 单个模式、剪贴板粘贴与 Ctrl+Enter；「队列下载」查看与管理任务，下载中不再打断输入
- **设置页分类导航**：下载位置、画质与格式、网络与代理、Cookies、下载引擎，左侧选择、右侧配置，支持恢复默认 / 撤销 / 保存
- **关于页重做**：版本信息与作者链接（GitHub、CNB、哔哩哔哩、个人网站）

### FFmpeg

- **加速镜像下载**：安装弹窗提供 GHFast / GH-Proxy 两个 GitHub 加速链接，一键跳转浏览器
- **导入安装包**：下载 `.7z` / `.zip` 安装包后选择该文件，程序自动解压到程序目录并关联 `bin` 下的可执行文件，装完即用
- 保留自动下载安装与手动选择 `ffmpeg.exe` 两种方式

### 其他

- 设置页可一键打开程序数据目录（任务队列与设置的存放位置）
- 底部状态栏实时显示 yt-dlp / FFmpeg / 代理状态
- 界面中状态更新改为局部刷新，下载过程中滚动与输入不再被打断
