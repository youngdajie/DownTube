## DownTube 1.3.1

新增「百宝箱」页，把下载之外的三件事收在一处：抖音插件推荐、音视频合并分离、视频压缩。

### 新增：百宝箱

左侧栏新增第四个入口，点开是三块内容。

**推荐 —— 抖音网页端更好用的办法**

推荐一个 Tampermonkey 脚本（Edge 插件）。装上之后抖音网页端可以直接下载视频，页面上的干扰元素也会一并清掉。**下载抖音视频优先用这个插件**，比在下载队列里贴链接更稳，画质也更完整。

**FFmpeg 工具 —— 合并与分离**

- 合并：选一个视频、再选一条音频，合并成一个完整视频
- 分离：把一个视频拆成独立的视频流文件和音频流文件

两个操作都是**无损流复制**，不重新编码，瞬间完成，画质一点不变。

**视频压缩 —— 让文件变小**

| 输出格式 | 说明 |
| --- | --- |
| MP4 · H.264 | 兼容性最好 |
| MP4 · H.265 | 体积最小 |
| WebM · VP9 | 网页播放 |

压缩率三档：高画质（几乎看不出差别）、均衡（默认）、小体积（画质有可见损失）。

自动使用显卡编码器加速，没有可用显卡时回退 CPU。

### 其他改进

- **下载页的平台文案分级**：YouTube 与哔哩哔哩单独标为「最佳」，加粗强调；其他平台用浅色带过，不再混在一起
- **左下角加了个小图标**：平时是虚化的，鼠标移上去会变清晰
- 百宝箱里的下拉菜单和开关换成了与设置页一致的样式

### 说明

**输出的文件夹每次都会弹窗询问**，不自动保存，也不会记住上次的位置。

中断的下载仍支持续传，重新开始会接着上次的进度继续。
