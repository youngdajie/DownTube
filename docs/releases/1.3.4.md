## DownTube 1.3.4

**紧急修复**：1.3.3 的「视频压缩」和「视频音频合并」在输出 MP4 时完全用不了，任何文件都处理不出来，只会报一句看不懂的英文错误。

如果你要用这两个功能，请更新到这一版。已经装 1.3.3 的话，直接在应用里更新即可。

### 修好了：压缩和合并不出文件

1.3.3 我改了一处编码参数，不小心把**输出文件的路径**弄丢了 —— 相当于告诉 FFmpeg「开始干活」但没说要输出到哪，它就直接报错了

MP4 是压缩的默认格式，所以这个功能一打开就是坏的

现在正常了。合并、分离、压缩三块都验证过能产出文件

### 顺便修好的三个显示问题

**失败却显示成绿色**

出错时的提示条本该是红色，实际却是绿色的，看着像成功了。已经改对

**失败时标题写着「已完成」**

明明报错了，进度标题还写着「已完成」。现在会明确写「处理失败」，并且变成红色

**报错是英文**

之前直接甩出一句 `At least one output file must be specified`。现在这类 FFmpeg 内部报错都会翻成中文，比如「没有指定输出文件」「找不到文件」「没有写入权限」

### 说明

**输出的文件夹每次都会弹窗询问**，不自动保存，也不会记住上次的位置。

中断的下载仍支持续传，重新开始会接着上次的进度继续。
