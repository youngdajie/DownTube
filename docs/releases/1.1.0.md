## DownTube 1.1.0

体验细节打磨版：全界面文案的标点排印统一，关于页观感修正；发版流程升级为 CNB 与 GitHub 双平台自动构建。

### 界面

- **文案标点统一**：全界面提示文案统一使用中文全角标点（逗号、分号、冒号），句尾不再带句号，排版更整齐
- **关于页**：应用图标与文字块垂直居中，观感更平衡

### 其他

- **双平台自动发版**：新增 GitHub Actions 流水线，与 CNB 流水线等效——推送 `V1.1.0` 标签后，两个平台各自自动构建并发布安装包，互不干扰
- 安装包命名与发布策略不变：`DownTube-Setup-<版本号>-<构建编号>.exe`，仅保留当前版本的 Release
